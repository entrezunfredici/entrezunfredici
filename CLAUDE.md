# CLAUDE.md — Instructions pour Claude Code

> Ce repo est le **profile README** GitHub de entrezunfredici (repo au même nom que le compte :
> son `README.md` s'affiche automatiquement en haut du profil GitHub). Il n'y a pas de code
> applicatif ici, juste du Markdown/HTML (et éventuellement des images) à concevoir et itérer.

## Règles rapides

- Le repo est bilingue : `README.md` (français, affiché sur le profil GitHub) et `README.en.md` (anglais), reliés par un lien de bascule en tête de chaque fichier.
- **Toute modification de contenu doit être répercutée dans les deux fichiers** (`README.md` et `README.en.md`) — pas de mise à jour d'un seul des deux, même pour un petit changement (typo, lien, nouvelle section...).
- Rester dans le sous-ensemble Markdown/HTML supporté par le rendu GitHub (pas de CSS custom, pas de JS).
- Éviter le contenu générique/placeholder (badges vides, sections "à remplir") — préférer un contenu concret et à jour.
- Avant de committer une image, vérifier son poids (le profil doit rester rapide à charger).
